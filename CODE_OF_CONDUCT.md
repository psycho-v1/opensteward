# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in OpenSteward a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, experience level, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our standards

Examples of behavior that contributes to a positive environment include respectful discussion of scientific disagreement, accepting correction, and focusing critique on the registry rules rather than on people.

Examples of unacceptable behavior include harassment, publication of others' private information, and sustained disruption of review.

## Enforcement

Report conduct problems by opening a confidential GitHub security advisory, or by contacting the repository maintainers. Maintainers will remove comments, commits, or contributions that violate this code.

This code is adapted from the Contributor Covenant, version 2.1.
